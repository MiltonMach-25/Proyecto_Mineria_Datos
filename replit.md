# ShopPredict en Replit

- La aplicación activa está en `Entregable_Final_ShopPredict`.
- Usa `.replit` en la raíz para ejecutar el servidor Python.
- `app.py` sirve los archivos estáticos y `/api/stats` desde el CSV incluido; no instales dependencias para esta aplicación.
- No se requieren servicios externos ni credenciales.
- Conserva las cifras verificadas y no inventes métricas para Naive Bayes, KNN o clustering.
- Las tres diapositivas de métodos numéricos deben mantenerse.
